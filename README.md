# Have You Tried Turning It Off? — v2

One funny single-line reply from a hopeless tech support agent to a desperate customer:

> Great news — I turned myself, the office, and the whole building off and on again, and honestly I feel fantastic now, so your ticket is closed as resolved!

The program (`main.ts`, Node 22, standard library only) writes exactly that line — and nothing else — to `/output/entry.txt`.
